## Étapes

1. Lire le WIP : `git show 9866a6a --stat`, puis le diff de code (`git diff cbbb479 HEAD --
   crates/ games/ CLAUDE.md docs/`) avec la checklist `CLAUDE.md`. Vérifier en particulier :
   - `loot_drop_on_death_system` : tirage dans `RngStreams` flux `loot`, ennemis traités dans
     l'ordre des `GgrsNetId` (`order_iter!`), aucune `HashMap`, aucun `f32` ;
   - ramassage : distance en `Fixed`, un seul ramasseur déterministe si deux joueurs sont à
     portée (tri par `net_id`), `despawn_rollback()` ;

     de points appliqué dans `economy.rs` (`award_points_system`) ;
