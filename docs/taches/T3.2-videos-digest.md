# T3.2 — vidéos et digest de fin de M0 (1 j)

Lire d'abord `docs/taches/README.md`. Dépend de T3.1. Branche : `m0-v4-videos-digest`.
Il faut `ffmpeg` et un affichage (ou un serveur X virtuel) pour les vidéos.

## Contexte

- Vidéos : `scripts/scenario-video` (`make videos [SCENARIO=a,b]`, `make compare_video
  SCENARIO=<nom> BASE=<réf>`), sorties `target/videos/<commit>/`, page de revue
  `target/videos/index.html` (`make review_videos`), moments clés `*.events.json`.
- Métriques de bots : `alacod-sim` (`crates/scenario/src/bin/alacod-sim.rs`) :
  `cargo run -q -p scenario --profile headless --bin alacod-sim -- --game zombies --bots 4
  --profiles fonceur,fonceur,prudent,immobile --seeds 1..20 --until-wave 5 --max-frames 20000
  --json /tmp/sim.json` (JSON : une entrée par graine : vague atteinte, frames, kills, desync).
- Notes de revue : `tests/review-notes/<commit>.md` (format de `scripts/nightly.sh` : sections
  « A. Bench », « B. Sim », « C. P2P », vidéos).
- Référence de comparaison : la dernière vidéo de la vague 0 de M0 — `main` à `4e93269`
  (journal §10, « base de référence »).
- Spécification : « Montage, comparaison avec la dernière vidéo de M0 vague 0, digest écrit avec
  les métriques de bots. »

## Livrables

1. Vidéos des scénarios du clone : `make videos SCENARIO=clone_solo,clone_duo,clone_quad` (+ le
   montage automatique), et la comparaison avant/après `make compare_video SCENARIO=idle
   BASE=4e93269` (même scénario joué par le code de la vague 0 et par `main`).
2. `alacod-sim` sur 20 graines à 4 bots jusqu'à la vague 5 : tableau (graine, vague atteinte,
   frames, kills, desync = 0 partout).
3. Digest `docs/digests/m0-fin-de-vague-2.md` : ce que le clone sait faire (une ligne par
   chantier livré, avec la tâche), les chiffres (scénarios, fps de bench, tableau alacod-sim),
   les liens vers les vidéos (chemins `target/videos/<commit>/…`, à copier dans `docs/digests/videos/`
   si < 5 Mo chacune, sinon lien seulement), ce qui manque pour M0 (plan §9.8) et les dettes
   ouvertes du journal.
4. `tests/review-notes/<commit>.md` : notes de revue (ce qui est visible/anormal dans chaque
   vidéo), à compléter par T3.3 (revue humaine).

## Étapes

1. `make test_scenarios` vert sur `main` fusionné ; `make bench` ; `alacod-sim` (exit 0).
2. Vidéos, montage, comparaison ; ouvrir la page de revue et regarder chaque vidéo.
3. Écrire le digest et les notes ; commit ; merge (§6) ; journal.

## Critères d'acceptation

- Les fichiers du digest et des notes existent et citent des chiffres réels ; `alacod-sim`
  sans desync ; vidéos générées (et regardées).
